HAR import

Teach the engine your dashboard's private endpoints from a browser capture. Cookies and auth headers are redacted before anything is stored.

  1. Open the MoEngage dashboard in Chrome or Firefox and log in.
  2. Open DevTools (F12) → Network tab.
  3. Enable Preserve log and clear the list.
  4. Click through Campaigns, Segments and Flows so their list pages load.
  5. Create or edit a segment and save it as a draft (this captures write endpoints without sending anything).
  6. Right-click the request list → Save all as HAR with content.
  7. Upload the .har file here. It is parsed locally and never leaves this machine.
